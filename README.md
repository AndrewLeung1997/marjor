# 麻雀消消樂

中國麻雀版 Candy Crush 三消遊戲，使用 React + Vite + TypeScript 製作。

## 功能

- **限時計時**：每關有倒數時間，時間到即失敗
- **炸彈道具**：四連生成排炸彈（↔/↕），五連生成範圍炸彈（💥），可連鎖引爆
- **34 種牌面**：一萬至九萬、一筒至九筒、一索至九索，以及東南西北中發白
- **每關 8–15 種牌**：萬筒索均衡搭配字牌，每關牌型組合不同
- **三種難度**：簡單（1–5 關）、中等（6–10 關）、困難（11–15 關）
- **關卡通關**：每關有步數限制與目標分數，達標即可通關並解鎖下一關
- **星級評價**：每關最多可獲得 3 星
- **進度儲存**：通關紀錄自動儲存至瀏覽器 localStorage

## 開始遊戲

```bash
npm install
npm run dev
```

在瀏覽器開啟 http://localhost:5173

## 建置

```bash
npm run build
npm run preview
```

## 玩法說明

1. 點選第一張牌，再點選相鄰的牌進行交換
2. 只有能形成三消的交換才會生效
3. 消除後新牌從上方落下，連鎖消除可獲得連擊加分
4. 在步數用盡前達到目標分數即可通關
5. 卡關時可使用「洗牌」重新排列牌面
